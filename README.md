# elonclub.cz

Statický web Elon Clubu z.s. postavený na Jekyllu a hostovaný na GitHub Pages.

- Nová novinka: přidejte soubor `_posts/RRRR-MM-DD-nazev.md` s hlavičkou `title`, `date`, `author`, `categories` a případně `image` (cesta v `assets/img/`).
- Stránky jsou Markdown soubory v kořeni (`srazy.md`, `kontakt.md`, ...), navigace a kontakty se nastavují v `_config.yml`.
- Vzhled je v `assets/css/site.css`, šablony v `_layouts/` a `_includes/`.

Po pushi do větve `main` GitHub Pages web sám sestaví a nasadí.
